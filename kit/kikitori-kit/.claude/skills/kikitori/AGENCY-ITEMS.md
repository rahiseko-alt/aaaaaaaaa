# 生命保険代理店の基本の聞き取り項目（固定）

営業から商談の内容を聞き取るときの、毎回同じ18項目。ねらいは2つ: **案件の進み具合**をつかむことと、**お客様情報**を漏れなくためること。
集計のため、**項目と ID は外さず・変えない**。当てはまらない項目は「該当なし」と答えてもらう（状態は回答済み）。商談に固有の論点は、末尾に「追加」（ID は X1, X2, …）として足す。
お客様は名前を伏せ、「法人A社」「40代個人」のように書いてもらう。健康状態・病歴は聞かない・書かない。

## P. 案件の進み具合
- P1. 商談の段階（初回・ヒアリング・提案・クロージング・成約・失注）〔事実〕
- P2. 今回の商談で前に進んだこと（何が決まったか。「話をした」ではなく決まったこと）〔事実〕
- P3. 提案した商品と、保障額・保険料（月額）〔事実〕
- P4. お客様の反応と、残っている懸念・断られそうな理由〔事実〕
- P5. 決める人と決める時期（本人だけか、配偶者・経営者・税理士なども関わるか）〔事実〕
- P6. ほかの保険会社・代理店でも検討しているか〔事実〕
- P7. 見込み度（A: 1か月以内に成約／B: 3か月以内／C: それ以降・未定）と、その根拠になったお客様の言動〔判断〕
- P8. 成約の予定月と、予定保険料（月額）〔判断〕
- P9. 次回の日程と、それまでに営業がやること〔事実〕
- P10. 失注・停滞している場合、その理由〔事実〕

## K. お客様情報
- K1. お客様の区分（個人か法人か）・年代・職業（法人なら業種と従業員数）〔事実〕
- K2. 家族構成（配偶者・子どもの人数と年齢。法人なら経営者の家族）〔事実〕
- K3. いま入っている保険（保険会社・種類・保険料・満期や更新の時期。他社分も）〔事実〕
- K4. お客様が気にしていること（死亡・医療・老後・教育資金・相続・事業保障など）〔事実〕
- K5. 予算（月額）〔事実〕
- K6. 住宅ローン・収入・資産のおおまかな状況〔事実〕
- K7. 紹介をもらえそうな人がいるか〔事実〕
- K8. 今後の声かけの時期（更新・満期・出産・進学・退職などの予定）〔事実〕
