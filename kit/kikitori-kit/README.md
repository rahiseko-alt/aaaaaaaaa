# 聞き取りツール kikitori の使い方

このフォルダを Claude Code で開くと、聞き取りツールが使えるようになります。入れる作業は要りません。

## 1. このフォルダを Claude Code で開く

お使いの形に合わせて、どれか1つを行ってください。

**デスクトップアプリ（Claude アプリの「Code」）**
1. Claude アプリを開き、「Code」を選ぶ
2. 作業するフォルダを選ぶ画面で、この `kikitori-kit` フォルダを選ぶ

**VS Code**
1. VS Code の「ファイル」→「フォルダーを開く」で、この `kikitori-kit` フォルダを開く
2. Claude Code の画面を開く

**ターミナル（黒い画面）**
1. ターミナル（Windows は PowerShell）を開く
2. `cd ` と打ち（cd の後ろに空白を1つ）、この `kikitori-kit` フォルダを画面にドラッグして Enter を押す
3. `claude` と打って Enter を押す

最初に「このフォルダを信頼しますか」と聞かれたら、「はい」を選んでください。

## 2. 聞き取りを始める

入力欄に、次のように話題を添えて送ります。

```
/kikitori 生命保険の商談を記録するアプリを作りたい
```

あとは質問に答えていくだけです。「おすすめで」と答えれば、おすすめの答えを選んだことになります。
途中でやめるときは「ここまでで報告書にして」と送ってください。

## 3. 報告書

聞き取りが終わると、このフォルダの中の `docs/reports/` に報告書が保存されます。内容がほかの人に送られることはありません。

## 注意

- 実名・連絡先・健康状態などの個人情報は入力しないでください。
- ブラウザ版の Claude Code（claude.ai/code）では、このフォルダは使えません。
