生命保険代理店の、営業向け商談聞き取りツール kikitori を、私のパソコンの Claude Code に組み込んで、そのまま聞き取りを始めてください。

1. 次のファイルを取り寄せて、同じ名前で保存してください（フォルダが無ければ作ってください。すでにあれば上書きで構いません）。
   `~/.claude/skills/kikitori/` に保存するもの:
   - https://raw.githubusercontent.com/rahiseko-alt/aaaaaaaaa/main/kit/kikitori-kit/.claude/skills/kikitori/SKILL.md
   - https://raw.githubusercontent.com/rahiseko-alt/aaaaaaaaa/main/kit/kikitori-kit/.claude/skills/kikitori/REPORT-FORMAT.md
   `~/.claude/skills/grilling/` に保存するもの:
   - https://raw.githubusercontent.com/rahiseko-alt/aaaaaaaaa/main/kit/kikitori-kit/.claude/skills/grilling/SKILL.md
   - https://raw.githubusercontent.com/rahiseko-alt/aaaaaaaaa/main/kit/kikitori-kit/.claude/skills/grilling/LICENSE
2. 保存できたら、`~/.claude/skills/kikitori/SKILL.md` を読み、その手順どおりに聞き取りを始めてください（聞き取りそのものは、保存した `~/.claude/skills/grilling/SKILL.md` の手順どおりに進めてください）。

次回からは `/kikitori` と送るだけで始められることも、最後に一言教えてください。
