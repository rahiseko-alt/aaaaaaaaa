保険代理店向けの聞き取りツール kikitori を、私のパソコンの Claude Code に組み込んで、そのまま聞き取りを始めてください。

1. 次の3つのファイルを取り寄せて、`~/.claude/skills/kikitori/` フォルダに同じ名前で保存してください（フォルダが無ければ作ってください。すでにあれば上書きで構いません）。
   - https://raw.githubusercontent.com/rahiseko-alt/aaaaaaaaa/main/kit/kikitori-kit/.claude/skills/kikitori/SKILL.md
   - https://raw.githubusercontent.com/rahiseko-alt/aaaaaaaaa/main/kit/kikitori-kit/.claude/skills/kikitori/REPORT-FORMAT.md
   - https://raw.githubusercontent.com/rahiseko-alt/aaaaaaaaa/main/kit/kikitori-kit/.claude/skills/kikitori/AGENCY-ITEMS.md
2. 保存できたら、保存した `SKILL.md` を読み、その手順どおりに聞き取りを始めてください。
3. 話題: ここに聞き取りたい商談を書く（例: 今日の40代個人のお客様との見直しの商談。書かなければ最初に聞いてください）

次回からは `/kikitori 話題` と送るだけで始められることも、最後に一言教えてください。
