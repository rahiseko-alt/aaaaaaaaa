# 聞き取りそのものは grilling をそのまま使う

利用者の指示: 聞き取りの肝は mattpocock/skills の grilling（/grill-me が呼ぶもの）であり、1文字も削らない・変えない。独自に書いた聞き方（1回5問・深掘り3回で打ち切り・「例」の付け方など）には意味がない。

そのため kikitori は聞き方を持たず、Skill ツールで grilling を起動し、毎回入力すると無駄な「最初の設定」（ADR-0004 の内容）だけを固定の文として渡す。独自に作った18項目も渡さない。終わった後に決まった形の報告書にして保管する部分だけを受け持つ。配布物には grilling の手順書を書き換えずに同梱する（MIT ライセンスの表示を添える）。
