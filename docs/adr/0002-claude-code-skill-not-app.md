# 聞き取りの道具は、アプリではなく Claude Code の部品として作る

当初は生命保険の商談を記録するスマホ向けページを作る予定だったが、デモとして汎用的に見せたいこと、項目づくりと質問に AI を使うことから、Claude Code の中で動く部品（利用者が一語の合図で起動するもの）として作る。画面や AI の鍵の管理が不要になり、この置き場所の用語集・決定記録をそのまま読み書きでき、報告書も同じ置き場所に残せる。代わりに、Claude Code を使わない人は使えない。

## Considered Options

- スマホ向けのページ（ADR-0001）: 外部通信なしでは AI を使えず、汎用の聞き取りにならない。
- claude.ai 上のページから Claude を呼ぶ形: 鍵は不要だが、画面の作り込みが要り、置き場所の記録を読めない。
