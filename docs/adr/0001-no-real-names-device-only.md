# 実名・健康状態を記録せず、記録はスマホの中だけに置く

所属先の生命保険会社が、私物のスマホや社外の保存先へのお客様の個人情報の持ち出しを認めているか、決めた時点では確認できていない。そのため、お客様は実名ではなく呼び名で記録し、健康状態の欄は設けず、記録は営業職員のスマホの中だけに保存する（Google スプレッドシート等の外部保存は採らない）。スマホの紛失・故障で記録が消える危険は、手動の書き出し機能で補う。

## Consequences

- 規則が「持ち出し可」と確認できれば、実名・外部保存への切り替えを検討してよい。その場合はこの記録を置き換える。
- 呼び名から本人を特定できる書き方（フルネームの一部など）をしない運用は、営業職員側の注意に委ねる。
