# 設定のロック: 生命保険代理店で、営業から商談を聞き取り、決まった形で保管して集計する

利用者の指示により、次の設定を固定する。手順書（SKILL.md）の「前提」にも同じことを書き、変えない。

- 使うのは生命保険代理店。
- 答えるのは営業。この道具は、営業から、営業とお客様との商談の内容を聞き取る。
- 話題は商談に固定し、聞かない。
- ねらいは、案件の進み具合をつかむことと、お客様情報をためること（利用者が選んだ）。
- 聞き取り項目は AGENCY-ITEMS.md の18項目（ID P1〜P10・K1〜K8）を毎回そのまま使う。外さない・言い換えない。当てはまらなければ「該当なし」。固有の論点は「追加」（X1〜）。
- 結果は REPORT-FORMAT.md の決まった形（冒頭の集計用の欄と、ID つきの表）で保管し、管理する人が何件分もまとめて集計できるようにする。

項目を毎回足し引きできると、件数をまとめて集計できなくなるため、項目と形を固定した。ADR-0003 の「話題に合わない項目は外す」はこの記録で置き換える。
