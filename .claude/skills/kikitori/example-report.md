# 聞き取り報告書: 生命保険の商談記録アプリ

- 報告書の状態: 途中で終了
- 話題: 生命保険の営業職員が、商談の内容をスマホで記録するアプリを作りたい
- 日付: 2026-10-04（最終更新: 2026-10-04）

## 要約

営業職員がひとりで、面談の直後にスマホで記録する簡易なアプリを想定している。お客様は呼び名で記録し、実名と健康状態は残さない。
記録の保存先と、所属先の規則で私物のスマホにお客様の情報を入れてよいかは決まっていない。
利用者の求めにより、未回答を2項目残して途中で終了した。

## 不明な点

- 所属先の規則で私物のスマホにお客様の情報を入れてよいか: 3回聞き直しても、規則を確認していないとのことで答えが出なかった。
- 募集の記録として残す義務: 利用者が「わからない」と答えた。

## 次に確認すべきこと

- 所属先のコンプライアンス担当に、私物のスマホでの記録の可否と、記録に残すべき項目を確かめる（利用者）。
- その答えを受けて、記録の保存先と、失くしたときの備えを決める。
